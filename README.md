# SignWithChikky

SignWithChikky is an Indian Sign Language (ISL) learning platform designed to make sign language learning more accessible, organized, and beginner-friendly.

## Features

* ISL Dictionary
* Topic-Based Learning
* Interactive Flashcards
* Quizzes
* Learning Roadmap
* YouTube & Instagram Integration

## Website:
https://signwithchikky-rho.vercel.app/

## Vision

The long-term vision of SignWithChikky includes:

* Comprehensive ISL learning resources
* Sign language datasets
* Sign recognition technology
* Accessible learning applications

Currently under active development.
